- 3σ 以上は cvi_high の1本。登録どおり lin_b2yf への上積みを見積もる: 2e-4 ×(0.041 / 0.154)² ≈ 1.4e-5。基準の 1e-4 に届かないので、結合しない。最終2本の差し替えも要らない(judge_day の確定で 1e-4 を越えたときだけ見直す)。
- 5本を並べた中の 3.2σ なので、5 本の補正(Bonferroni)をしても片側 p ≈ 0.004 程度。偶然とは言いにくいが、10/25 の cvi_low(登録済み)で逆向きが出るかを見て「単調」と言えるかを決める。
- Discovery の読み: 気候脆弱性(CVI)の高い tract では、地図の欠けが、基準の特徴(道路・施設・農村・地域)で説明できる分より大きい。SVI(10/23、1.1σ)や危険 × SVI(−1.6σ)では出ないので、社会的脆弱性ではなく、CVI に含まれる気候・健康・インフラの側に効いている可能性がある。山火事の危険度の高い tract は、予測に反して説明より小さい側(1.8σ、未確定)。
- 受付の付記(10/24 朝)を受けた扱い: cvi_high は単独の当たりとして書かない。10/25 の cvi_low が逆向き(2σ 以上)に出て単調性が確かめられたときだけ、Discovery で「気候脆弱性の高い tract ほど欠けが基準の説明より大きい」と書く。出なければ「多重比較の範囲内の1本」と書く。
- 試したプローブの総数(writeup に併記する): 単独プローブは probe_log.csv に 98 本(全期間)。そのうち Discovery の切り口(10/22〜25)は 20 本。偏りが無くても、両側 3σ を1本以上越える確率は 20 本で約 5%、98 本で約 23%。
