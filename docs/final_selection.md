# 最終評価の2本の選び方(2026-10-04 決定案)

最終順位は非公開 70% で決まる。公開 30% の順位をそのまま信じず、次の基準で2本を選ぶ。

## 公開スコアの揺れの見積もり(`scripts/selection_noise.py`)

正解を y = p(lin_v3) + ε(ε は tract ごとに独立、SD = 実測 RMSE 0.0673)と置き、公開/非公開の分け方を 4,000 回引き直した。

| 比較 | 公開での差 | 公開と非公開の差のずれ(SD) | 順位が入れ替わる確率 |
|---|---:|---:|---:|
| lin5_v2 − lin_v3 | +0.0031〜0.0038 | 0.0006 | 0 |
| lin4_v1 − lin_v3 | +0.0028〜0.0036 | 0.0006 | 0 |
| const 0.1 − lin_v3 | +0.028〜0.032 | 0.0015〜0.0020 | 0 |
| lin_v3 単体の公開 − 非公開 | | 0.0011(正規)/ 0.0031(t3) | |

(誤差が正規の場合と、裾の重い t 分布(自由度3)の場合。どちらも結論は同じ。)

読み方:
- **提出どうしの差は、公開で 0.0012(ずれの SD の2倍)以上あれば非公開でもほぼ同じ向き**。それ未満の差では順位を信じない。
- 1本の絶対値は ±0.001〜0.003 動く。非公開の最終値は公開の値から多少ずれる前提でいる。

このモデルが見ていないもの(だから2本目で備える):
1. 正解を lin_v3 の周りに置いているので、lin_v3 に有利な前提になっている。
2. **重みを公開 30% で測った共分散から解いている**。公開の分け方の偶然に合わせた分は、非公開では戻ってこない。期待 RMSE が実測より毎回 0.004〜0.005 楽観的だったのと同じ種類の偏りで、特徴を増やすほど大きくなる。
3. 誤差の大きいプローブ(0/1 フラグ、相関の SD 0.078)に乗った重みは、公開の偶然を拾いやすい。

## 選ぶ基準

**1本目: 公開で最良の結合。** ただし次をすべて満たすこと。
- 使う特徴がすべて、機構の説明がつくもの(道路の倍率・地域の傾き・施設の手がかり)。
- 2番目の候補より公開で 0.0012 以上良い。満たさないときは、特徴が少ない方を1本目にする。

**2本目: 誤り方の違う版(10/5 改訂)。** 1本目と予測の相関が 0.98 未満で、期待 RMSE の差が 0.003 以内のもの。
特徴の「系統」を変える。2026-10-05 時点の手元計算(lin_v3 を1本目とした場合):

| 2本目の候補 | 期待 RMSE | lin_v3 との予測の相関 |
|---|---:|---:|
| 道路+地域の傾き(施設フラグなし) | 0.06411 | 0.976 |
| 道路だけ(t_k14) | 0.06493 | 0.962 |
| 合成推定+施設フラグ(道路の倍率なし) | 0.06794 | 0.909 |
| 1本目の重みを 0.85 倍に縮めた版 | 0.06331 | **1.000**(一次変換なので誤り方は同じ。保険にならない) |

10/4 版にあった「重みを縮めた版」は撤回する。重みを一律に縮めて切片を合わせ直すのは予測の一次変換で、
1本目との相関が 1.0 になり、誤り方が変わらない(wiki: final-picks-must-differ)。

**1本目の作り方の候補**: 特徴の組を変えた複数の結合の平均。単一の最良構成を選ばず、構成を混ぜるのが分散を下げる
(wiki: ext-timeseries-geo-winning-patterns の P13、降水量予測の1位は分割の違う 63 モデルを混ぜた)。締切前に期待値で比べる。

**分割の構造は分からない(10/5 追記)。** 上の揺れの見積もりは、公開 30% が tract ごとに無作為に選ばれている前提。
Zindi の地理系コンペには、公開/非公開を空間グリッドで分けた例がある(Urban Heat Island、スタッフ回答。wiki:
spatial-group-cross-validation)。空間でまとまって分かれていれば、公開と非公開のずれはこの見積もりより大きい。
そのため差 0.0012 は下限として扱い、2本目は必ず誤り方の違う版にする。
確かめる方法(任意、2枠): 地域の0/1指標を縮尺 2 種で出すと、公開に含まれるその地域の割合 E_pub[1_r] が解ける
(RMSE² = E[y²] − 2a·E_pub[y·1_r] + a²·E_pub[1_r] で未知数2つ)。約 30% なら地域単位では無作為。

**選ばないもの**
- 1本目とほぼ同じ予測(相関 0.995 以上)の2本目。保険にならない。
- 単独プローブの提出(特徴をそのまま出したもの)。

## 締切前の手順

1. 締切の2〜3日前に、最良の結合と、誤り方の違う2本目(予測の相関 0.98 未満)を両方提出して公開スコアを得る(各1枠)。
2. 上の基準で2本を選び、選んだ理由(公開スコア・差・特徴数)をこのファイルに追記する。
3. Zindi の「提出を選ぶ」画面で選択する(**提出の選択はユーザーの承認を得てから**)。

**下書きの結論**: 1本目は lin_v5(またはそれより 90% 点で 0.0012 以上良い後継)。2本目は lin_v3 ではなく、施設成分なしの版。
理由: lin_v3 は lin_v5 と相関 0.983 で保険にならない。施設成分なしの版は誤り方が違い(相関 0.972)、90% 点の差も 0.0012 で基準内。
公開スコアで 0.0012 未満の差は信じない方針なので、「公開が良いほうを2本」ではなく「誤り方の違う2本」を選ぶ。
未提出の2本目は、締切の2〜3日前に1枠使って公開スコアを確かめる(予測: 点の期待 0.0633 + 0.004〜0.005 = 0.0673〜0.0683)。
公開分割の検証(10/8・10/9 のテキサスの割合)で偏りが確認されたら、公開スコアの重みをさらに下げ、この下書きのまま選ぶ。

## 2本の違いはどこに出るか(10/7 午後)

正解が無いので地域ごとの RMSE は出せない。代わりに、2本の予測の差(lin_v5 − 施設成分なし)を地域 × 都市/農村で数えた。

| 地域 | 農村: 平均差 / 差が 0.02 超の割合 | 都市: 平均差 / 差が 0.02 超の割合 |
|---|---|---|
| eastern-ok | +0.0087 / 39% | −0.0053 / 15% |
| eastern-wa | +0.0078 / 27% | −0.0008 / 12% |
| maricopa-az | +0.0092 / 29% | −0.0017 / 12% |
| northern-ca | +0.0120 / 44% | −0.0004 / 14% |
| south-central-tx | +0.0100 / 37% | −0.0021 / 14% |

全体では 18% の tract で差が 0.02 を超える。差はどの地域でも農村に集まり、向きも同じ(lin_v5 が農村を約 0.01 高く出す)。
したがって2本目は「施設の推定が農村で外れたとき」の保険として働く。地域ごとの揺れではなく、農村の比率で効き方が決まる。
非公開側で農村の比率が公開側と違えば2本の順位が入れ替わりうる。そうなっても、どちらかが当たる組み合わせになっている。

### 正解側から見た2本の外れ方(10/7 16時、`scripts/subgroup_check.py`)

0/1 フラグのプローブから集団の正解平均 E[y|x=1] = E[y] + cov/P を解き、2本の予測平均と比べた(モデル外のフラグだけで照合)。

| 集団(割合) | 正解平均 | lin_v5 | 施設成分なし |
|---|---:|---:|---:|
| 都市 ∧ 消防なし(64.0%、差で導出) | 0.041 | **0.043** | 0.051 |
| 農村 ∧ 消防なし(6.6%) | 0.112 | 0.092 | 0.094 |
| 農村 ∧ 消防あり(12.3%、差で導出) | 0.108 | 0.119 | **0.103** |
| 消防なし ∧ fire_protection_service あり(6.2%) | 0.099 | 0.071 | **0.083** |
| 消防あり ∧ EMS なし(24.5%) | 0.066 | 0.088 | **0.069** |

施設フラグは最大の集団(都市の消防なし)で効き、小さな集団で行き過ぎる。集団平均のずれが MSE に足す分は lin_v5 0.00021、
施設成分なし 0.00011(重なりあり)で、全体の期待 MSE の差 0.00023 と同じ桁。どちらも他方を支配しないので、2本目の役割は保たれる。
「消防なし」の符号は都市(0.041)と農村(0.112)で逆向き。単一の重みでは表せない。ems0_fire1 を足す結合は、
重みの打ち消し(SD 0.0086)で 10/6 に不採用にしており、この表は加えずに説明に使う。

### なぜ施設成分なしの版が勝ったか(10/9 昼、`scripts/why_alt_won.py`)

2本とも特徴の線形結合なので、MSE の差をプローブの値だけで分解できる(採点される行のモーメント、測り直した消防の値)。
予測される差(lin_v5 − alt)+0.000191 に対し、実測 +0.000154(0.06641² − 0.065236²)。分解はおおむね当たっている。

| 集団(割合) | 正解の平均 | lin_v5 | alt | P·偏り²(v5 / alt) |
|---|---:|---:|---:|---:|
| 消防の施設あり(29.3%) | 0.068 | **0.089** | 0.071 | **0.000128** / 0.000002 |
| 消防の施設なし(70.7%) | 0.056 | **0.048** | 0.055 | 0.000051 / 0.000001 |
| 消防あり・EMS なし(24.4%) | 0.066 | **0.088** | 0.069 | 0.000118 / 0.000002 |
| 農村(18.3%) | 0.111 | 0.112 | **0.102** | 0.000000 / 0.000015 |
| 南中部TX(64.0%) | 0.050 | 0.052 | 0.052 | ほぼ 0 |

**機構**: 差のほぼ全部が「消防の施設がある tract」で lin_v5 が 0.021 高すぎたことから来る。縮尺なしの旧値は「消防なし」の効きを
相関 −0.211 と大きく見積もっていた(測り直すと −0.060)。そのため lin_v5 は、消防のある tract を持ち上げ、無い tract を下げすぎた。
地域では差が出ない(テキサスとそれ以外で2本の偏りは同じ)。**都市・農村では、むしろ lin_v5 のほうが農村を正しく当てていた**
(alt は農村を 0.009 低く出す)。施設成分そのものが悪いのではなく、その重みを決めた測定が悪かった。
→ 測り直した値で組み直した lin_v5′ は、消防の偏りを直しつつ農村の当たりを保つはず(採点される行の点の期待 0.0638、alt 0.0641)。
10/10 の測り直し4本の後に組み直し、alt より 90% 点で 0.0012 以上良ければ出す。

> 注(10/9): 上の「正解側から見た2本の外れ方」の表は、縮尺なしの fire_none の旧値から導いた値を含む(都市・消防なし 0.041 など)。測り直した値では都市・消防なしは 0.051 で、「消防なしの意味が都市と農村で逆」は誤り(プローブの誤差だった)。最新は `python scripts/subgroup_check.py` と Documentation §5。
