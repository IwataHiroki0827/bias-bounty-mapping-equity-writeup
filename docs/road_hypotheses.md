# 道路の基準延長の取りこぼし: 仮説台帳(予測を先に書く)

背景: 番号つき路線による TIGER(S1100+S1200)近似 L_ref は、LB の格子で k = 1.4 倍が最良(相関 0.684。k = 2.0 も 0.683)。
倍率は「水準」しか直さないので、取りこぼしの「場所」を当てた特徴だけが相関を上げる(docs/competition-analysis.html §05-A)。
規約: 撤去済み参照データ由来の公開集計は使わない(10/3 ユーザー決定)。判定は LB の単独プローブだけ。

**採否の基準(共通)**: 新しい道路特徴は、単独プローブの相関が t_k14 の 0.684 を 0.05 以上上回るか、
t_k14 との相関が 0.98 未満で結合の期待値を改善するときだけ採る。t_k14 との相関 0.99 以上は「同じ1本」とみなし、枠を使わない。

## H4(10/15、Fable の案①): 取り込み時代の番号なし幹線 → 棄却

- 予測: 幹線4クラス(motorway/trunk/primary/secondary)に、2012 年より前から更新の無い番号なし区間が相当量あり、それが参照の S1200 に数えられて k=1.4 の取りこぼしを作る。
- 集計(scripts/build_road_age.py、10/15 14:26、全5地域で約1.5分): 取り込み時代の幹線は **5地域合計で番号なし 45 km・番号あり 0 km**(TX 39 km)。
  番号なし幹線の大半(TX 68,459 km・AZ 10,999 km)は 2012 年以降に更新されている。35333 の「採点4クラスの取り込み時代は 39.9 km(0.02%)」と一致。
- 結論: 幹線クラスの取り込み時代の区間は、量として取りこぼし(基準の約4割)を説明できない。プローブには出さない。
  取り込み時代の区間は minor クラス(tertiary 以下)に集中しており、幹線の参照には入らない。

## H5(10/15、事前登録): 名前で見る幹線(scripts/build_road_named.py)

- 機構: 名前が County Road・FM/RM・State Hwy/US/Hwy の型なのに、Overture では tertiary 以下に分類されている区間は、参照(S1200)には数えられ、Overture の幹線には入らない。
